# Build Roadmap

## Foundation — implemented in this repository baseline

- original branding placeholder: LedgerLands;
- npm workspace monorepo;
- TypeScript shared contracts;
- deterministic property-trading engine;
- seeded dice and engine tests;
- server-authoritative API;
- WebSocket state broadcast;
- solo AI opponent;
- React board UI;
- practice ledger/faucet;
- PostgreSQL/Prisma schema;
- Aetherius manifest/capabilities/SDK adapter;
- Docker Compose;
- GitHub Actions CI.

## Next production phases

1. Persistent MatchStore using PostgreSQL and event replay.
2. Full auction, mortgage/unmortgage and trade negotiation engine.
3. More strategic AI policies and simulation benchmarks.
4. Ranked rating service and seasons.
5. Tournament state machine + idempotent settlement.
6. Quest/achievement/reward service using non-withdrawable practice/promotional balances.
7. Replay/spectator endpoints built from match events.
8. Authentication and Aetherius Identity integration.
9. Aetherius File/Storage, Settings, Search and Notification provider integration.
10. Original production board/token/card artwork.
11. Accessibility, localization, mobile/desktop packaging.
12. Testnet wallet/NFT/escrow adapters.
13. Economy simulator at large scale.
14. Security/compliance review.
15. Limited real-value beta only after the previous gates pass.
